### 为什么编程能教哲学？

当你写 `let x = 10` 时，你在做一个哲学断言："x 是 10"。当你写 `let mut x = 10` 时，你在宣告："我承认我在改变世界"。编程语言的每一个语法设计都不是中立的——它携带了一套世界观。

Intent 是刻意按这套世界观设计的语言。学 Intent 不是学"又一种编程语言"，而是**用精确形式重新思考你与世界的关系**。

### 这本书怎么读？

- **先跑代码**：每章开头有一段可运行的 Intent 代码（`examples/lesson_XX_*.intent`），先跑一遍看输出
- **再读哲理解析**：理解这段代码背后的哲学概念
- **然后自己改**：每章末尾有"进阶"练习，改一行代码，看结果怎么变

### 前置条件
- 安装 Python 3.10+
- `python3 src/mini_intent.py examples/lesson_01_wuwei.intent`
- 不需要任何编程基础——所有概念从零开始

## 第一部分：本体论——存在是什么？

### 第1章：无为之始 → `let` 声明

**运行**：`python3 src/mini_intent.py examples/lesson_01_wuwei.intent`

**哲学核心**：
- 王阳明"心外无物"——你声明的变量，才在你的世界中存在
- 老子"无为而无不为"——`let` 默认不可变，不需要额外努力去"保持不动"
- 道家的"如如不动"——变量的默认状态就是稳定的

**代码概念**：类型推断、`let` vs `let mut`、一切皆表达式

**关键体验**：你把所有 `let` 改成 `let mut` 再看一遍输出——感觉有何不同？

## 第二部分：认识论——我们如何知道？

### 第2章：知行合一 → `|>` 管道

**运行**：`python3 src/mini_intent.py examples/lesson_02_zhixing.intent`

**哲学核心**：
- 王阳明"知行合一"——知道一个函数存在（知）和实际调用它（行）应该是连续的
- 庄子"庖丁解牛"——数据顺着纹理流过每个处理步骤
- 管道不是语法糖——它改变了你的认知结构，从"嵌套"到"流动"

**代码概念**：`|>` 管道、`def` 函数定义、Lambda

**关键体验**：用嵌套写法重写管道链，感受"从里到外读" vs "从左到右读"

### 第3章：格物致知 → `match` 穷举

**运行**：`python3 src/mini_intent.py examples/lesson_03_gewu.intent`

**哲学核心**：
- 朱熹"格物致知"——把每一个事物格透了，知识自然来
- 马克思"具体问题具体分析"——不搞一刀切，每种情况单独处理
- `match` 穷举性检查——你敢说"全考虑了"，编译器帮你验证

**代码概念**：`match` 表达式、`enum` 枚举、`if` 守卫

**关键体验**：删掉一个分支，看编译器怎么提醒你"漏了"

## 第三部分：实践论——我们如何行动？

### 第4章：社会契约 → `requires/ensures`

**运行**：`python3 src/mini_intent.py examples/lesson_04_contract.intent`

**哲学核心**：
- 马克思"人是社会关系的总和"——每个函数活在社会关系中
- 卢梭"社会契约"——进门前签合同（requires），出门前验货（ensures）
- 王阳明"致良知"——良知不是感觉，是可验证的条件

**代码概念**：`requires` 前置条件、`ensures` 后置条件、`contract` 契约系统

**关键体验**：把 `b != 0` 改成 `b != 1`，看看调用 `safe_divide(10, 1)` 会不会报错

### 第5章：烦恼即菩提 → `Result + ?`

**运行**：`python3 src/mini_intent.py examples/lesson_05_bodhi.intent`

**哲学核心**：
- 禅宗"烦恼即菩提"——错误不是要消灭的东西，是要认识的
- 斯多葛"控制你能控制的"——区分"我的事"和"不关我的事"
- `Result<T,E>`——Ok 和 Err 是平等的两支，不存在"正常"和"异常"的二分

**代码概念**：`Result<T,E>`、`?` 操作符、`try/catch/finally`

**关键体验**：在 while 循环里放 try/catch，失败 3 次后继续——感受"受伤 ≠ 死亡"

## 第四部分：辩证法——事物如何发展？

### 第6章：辩证统一 → `class` 继承

**运行**：`python3 src/mini_intent.py examples/lesson_06_dialectic.intent`

**哲学核心**：
- 黑格尔"正题→反题→合题"——发展不是线性的，是螺旋上升的
- 马克思"扬弃"（Aufheben）——子类保留父类有用的，超越不够好的
- 萨特"存在先于本质"——你的行动定义了你是什么

**代码概念**：`class` 系统、继承、方法覆盖

**关键体验**：给函数链加一个 `negate` 环节，体会"否定不是消灭，是超越"

## 第五部分：系统论——万物如何连接？

### 第7章：万物一体 → `import` 生态

**运行**：`python3 src/mini_intent.py examples/lesson_07_ecosystem.intent`

**哲学核心**：
- 庄子"天地与我并生，万物与我为一"——你不需要自己造一切
- 王阳明"万物一体之仁"——标准库在你诞生前已经存在
- 你的工作不是发明，是组合——找到已有的模块，然后用管道串起来

**代码概念**：`import`/`export` 模块系统、列表/字典推导式、`range`

**关键体验**：用 `range` + 推导式 + 管道做一次数据流处理

### 第8章：向死而生 → `defer + 闭包`

**运行**：`python3 src/mini_intent.py examples/lesson_08_finitude.intent`

**哲学核心**：
- 海德格尔"向死而生"——出生时就知道了死亡，反而让生命有意义
- 道家"功成身退"——资源获取时就写下清理代码
- 王阳明"此心光明"——闭包携带诞生时的环境，无论在哪儿心都是亮的

**代码概念**：`defer` 语句、闭包、`yield` 生成器

**关键体验**：写一个带 `defer` 的函数，中间故意提前 `return`，看 defer 是否还执行

| 语法 | 含义 | 哲学映射 |
|------|------|---------|
| `let x = 10` | 不可变声明 | 如如不动 |
| `let mut x = 10` | 可变声明 | 改变世界 |
| `\|>` | 管道 | 知行合一 |
| `match x { ... }` | 模式匹配 | 格物致知 |
| `requires / ensures` | 契约 | 社会契约 |
| `Result<T,E>` | 结果类型 | 烦恼即菩提 |
| `?` | 错误传播 | 平常心 |
| `class / :` | 类/继承 | 扬弃 |
| `def / fn` | 函数/Lambda | 功夫 |
| `import / export` | 模块 | 天地一体 |
