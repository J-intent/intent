# collections

## `counter`

> counter — 数一数每个元素出现几次(存在的密度)

```intent
def counter(lst: Any)
```

| 参数 | 类型 |
|---|---|
| `lst` | Any |

## `most_common`

> most_common — 出现最多的前 n 个(键, 次数)对

```intent
def most_common(cnt: Any, n: Int)
```

| 参数 | 类型 |
|---|---|
| `cnt` | Any |
| `n` | Int |
