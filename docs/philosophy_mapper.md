# Intent 哲学映射器
## 让每一个语法特性都成为思维体验

> "心学为体，禅道为翼，马哲为用" — Intent 设计哲学

---

## 一、本体论层：一切皆表达式 (The One)

### 核心映射：`心即理也` → 代码即意图

| Intent 语法 | 哲学概念 | 思维体验 |
|------------|---------|---------|
| `一切皆表达式` | 王阳明"心外无物" | 没有"语句"和"表达式"的二分——你写的每一个东西都在**生成一个值**。就像你的每一个念头都在**生成一个存在状态** |
| `let x = 10` (默认不可变) | 禅宗"如如不动" | 声明即锚定。变量默认不能改——先确定"是什么"，再决定"怎么变" |
| `let mut x = 10` | 马克思"改变世界" | 显式宣告可变性。你要改变世界，必须**先承认你在改变** |
| `类型推断` | 庄子"大道不称" | 不需要到处标注类型，编译器能从上下文推断——就像道，不言自明 |

### 代码示例：如如不动

```intent
// 默认不可变：先确定"是什么"
let name = "Intent";
let pi = 3.14159;

// 显式可变：你必须承认"我要改变"
let mut counter = 0;
counter = counter + 1;  // 我承认我在改变世界
```

## 二、认识论层：管道与模式匹配 (The Process)

### 核心映射：`格物致知` → 数据流即认知流

| Intent 语法 | 哲学概念 | 思维体验 |
|------------|---------|---------|
| `\|>` 管道操作符 | 王阳明"知行合一" | 数据像一股水流从左到右穿过每个函数。你不嵌套调用，你**顺着数据的流动方向**思考 |
| `match expr { ... }` | 马克思"具体问题具体分析" | 面对一个值，穷举所有可能性。你**必须考虑所有情况**——漏了编译器就报错 |
| `Result<T, E>` + `?` | 禅宗"烦恼即菩提" | 错误不是异常需要捕获，错误就是**另一种返回值**。Ok 和 Err 是平等的两个子类型 |
| `\|> pipe` 链式处理 | 庄子"庖丁解牛" | 数据顺其纹理流过每个处理步骤，无需强行嵌套 |

### 代码示例：管道即思路

```intent
// 管道：顺着数据的流动方向思考
// 这不只是语法糖——它改变了你的认知结构
let result = data
    |> filter(is_valid)
    |> map(transform)
    |> reduce(combine, 0);

// 等价于心学式思维链：
// 先有 data → 过滤有效项 → 转换形式 → 聚合为结果
```

### 代码示例：pattern matching = 格物

```intent
// match 是你"格"一个值的穷举方式
let grade = match score {
    90..100 => "A",   // 这种情况
    80..89  => "B",   // 那种情况
    70..79  => "C",   // 必须覆盖
    _       => "F",   // 最后兜底
};

// 每一种可能性都是"一个物"
// 你格了 score 这个物，就穷尽了它的所有可能
```

## 三、实践论层：契约与错误处理 (The Practice)

### 核心映射：`实事求是` → 契约即合约

| Intent 语法 | 哲学概念 | 思维体验 |
|------------|---------|---------|
| `requires` 前置条件 | 马克思"人的本质是社会关系" | 进入一个函数前，你必须**声明你对世界的预期**。这是你和调用者之间的社会契约 |
| `ensures` 后置条件 | 王阳明"致良知" | 执行完函数后，你必须**证明你兑现了承诺**。良知不是感觉，是**可验证的条件** |
| `contract` 契约系统 | 马克思主义"实践是检验真理的唯一标准" | 契约不是注释——它会在运行时**实际执行验证**。如果你说谎，系统会告诉你 |
| `?` 错误传播 | 禅宗"平常心" | 遇到错误不恐慌，让它自然传播。Err 就是 Err，不是 exception，是**另一种正常状态** |

### 代码示例：契约即合同

```intent
// 前置条件：我要求 caller 的世界必须满足这些条件
// 后置条件：我保证返回的世界将满足这些条件
def divide(a: Float, b: Float): Float
    requires b != 0        // 进入函数前：我预期除数非零
    ensures result * b == a // 离开函数后：我保证结果可验证
{
    return a / b;
};
```

## 四、辩证法层：类与继承 (The Dialectic)

### 核心映射：`对立统一` → OOP 即辩证法

| Intent 语法 | 哲学概念 | 思维体验 |
|------------|---------|---------|
| `class A { this.x = x; }` | 黑格尔"自在的存在" | 类定义了事物的**本质属性**。`this` 是事物认识自身的方式 |
| `class B : A { ... }` | 马克思"扬弃" | 继承不是照搬——子类**扬弃**父类，保留有用部分、超越局限部分 |
| `方法覆盖` | 黑格尔"否定之否定" | 子类覆盖父类方法，不是删除，是在更高层次上**重新定义** |
| `枚举 enum` | 禅宗"不二法门" | 一个东西只能是几种状态之一。非此即彼，没有模糊地带 |

### 代码示例：继承即扬弃

```intent
enum ShapeType { Circle, Square, Triangle };

class Shape {
    def area(): Float { return 0.0; };  // 父类：抽象定义
};

class Circle : Shape {
    def area(): Float { return pi * r * r; };  // 子类：具体的否定
};
// Circle 扬弃了 Shape——保留了"有面积"这个属性
// 但用具体的计算公式取代了父类的抽象返回
```

## 五、系统论层：模块与闭包 (The System)

### 核心映射：`万物一体` → 模块即生态系统

| Intent 语法 | 哲学概念 | 思维体验 |
|------------|---------|---------|
| `import std.math;` | 庄子"天地与我并生" | 你不需要从零开始——整个标准库在你诞生之前就在那了 |
| `export fn_name;` | 马克思"人是社会关系的总和" | 你写的函数不是你私有的——暴露给外部，才成为**真实存在** |
| `闭包 fn(x) { ... }` | 王阳明"此心光明" | 函数携带它诞生时的环境。无论被传递到哪里，它永远记得"家" |
| `defer { ... }` | 道家"功成身退" | 资源获取时就知道何时释放。不是"别忘了清理"，而是**清理已经在等待着的** |

### 代码示例：闭包即记忆

```intent
def make_adder(n: Int) {
    return fn(x: Int) { return x + n; };
    // 这个匿名函数携带了 n 的记忆
    // 无论它被传到哪里，n 永远在它的作用域里
};

let add5 = make_adder(5);
print(add5(10));  // 15 —— 函数记得 5
```

## 六、修炼路径：用代码学哲学

### 第1课：无为之始
**哲学**：王阳明"心外无物"，老子"无为"
**Intent**：`let` 声明、类型推断
**体验**：不标注类型，系统自己知道。不写 mut，默认不可变。先观照，再行动。

### 第2课：知行合一
**哲学**：王阳明"知行合一"，马克思"实践是第一性的"
**Intent**：管道 `|>`、函数调用
**体验**：数据从左到右流动 = 从"知道"到"做到"。管道不是语法糖，是思维的重组。

### 第3课：格物致知
**哲学**：朱熹/王阳明"格物"，马克思"具体问题具体分析"
**Intent**：match 模式匹配、穷举性检查
**体验**：面对一个值，穷举所有可能。你敢说"我都考虑到了"，编译器会帮你验证。

### 第4课：社会契约
**哲学**：马克思"社会关系"，卢梭"社会契约"
**Intent**：requires/ensures 契约系统
**体验**：进门前签合同（requires），出门前验货（ensures）。代码之间的信任建立在可验证的条款上。

### 第5课：烦恼即菩提
**哲学**：禅宗"烦恼即菩提"，斯多葛学派
**Intent**：Result<T,E> + ? 操作符
**体验**：错误不是异常，是另一种正常返回值。你不再 try-catch 恐慌，你平静地处理每一种可能。

### 第6课：辩证统一
**哲学**：黑格尔辩证法，马克思"扬弃"
**Intent**：class 继承、方法覆盖
**体验**：子类不是照搬父类——它在更高层次上重新定义。每一次继承都是一次扬弃。

### 第7课：万物一体
**哲学**：庄子"天地与我并生"、王阳明"万物一体之仁"
**Intent**：import/export 模块系统、标准库
**体验**：你不需要自己实现一切。在你诞生之前，世界已经准备好了工具。你的任务是**组合**，不是**发明**。

### 第8课：临终关怀
**哲学**：海德格尔"向死而生"
**Intent**：defer 语句
**体验**：资源获取时就写下清理代码。不是"别忘了关文件"，而是"关文件的代码已经在路的尽头等你了"。
