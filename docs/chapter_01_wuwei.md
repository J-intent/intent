# 第1章：无为之始 — 心即理也

> **运行代码**：`python3 src/mini_intent.py examples/lesson_01_wuwei.intent`
> **哲学**：王阳明"心外无物"、老子"无为而无不为"
> **语法**：`let` 声明、类型推断、默认不可变

---

## 1.1 你声明，它就存在

打开终端，输入：

```intent
let name = "Intent";
print(name);
```

输出：`Intent`

这是你写的第一个 Intent 程序。只做了两件事：

1. 声明了一个叫做 `name` 的变量
2. 让它等于 `"Intent"`

但这里已经藏着一个哲学命题。

**在没有 `let name` 之前，`name` 不存在。**

王阳明说"心外无物"——花在深山自开自落，和你的心没有关系。但当你说"这朵花是红的"，花就在你的世界中诞生了。编程语言的 `let` 声明，就是把这个哲学命题翻译成精确形式：**一切需要先在代码中存在，才在程序的世界中存在。**

你和变量的关系，就是你和万物的关系。

---

## 1.2 系统比你知道更多

继续看这段代码：

```intent
let name = "Intent";   // ← 你没写这是 String
let pi = 3.14159;      // ← 你没写这是 Float
let flag = true;       // ← 你没写这是 Bool
let items = [1, 2, 3, 4, 5];  // ← 你没写这是 List
```

你从来没写 `let name: String = "Intent"`。但系统知道 `name` 是 `String`。

这叫**类型推断**。

大多数语言的哲学是"你告诉系统一切"。你写 `int x = 10`，你写 `String name = "Alice"`。你像一个焦虑的契约书写者，反复确认每一个细节。

Intent 的哲学不同。王阳明说"心即理也"——你的心本自知道。不需要向外求证，不需要逐项标注。系统推理出一切。

**你不标注类型，系统也全知道。因为你写下的=右边已经说明了一切。**

这不是技术妥协——这是刻意设计：**信任代码的诚实**。

---

## 1.3 默认不可变

```intent
let x = 10;          // x 不能被改变
let mut counter = 0; // counter 可以被改变
```

这里的差异很小——多一个 `mut`——但哲学差异巨大。

**`let` 默认不可变。`let mut` 才可变。**

大多数编程语言的哲学是"一切默认可变"——你的变量生来就可以被重写。你得额外加 `const` 或 `final` 来锁住它。

Intent 反过来。**不写 `mut`，就不给你变。**

这是老子的哲学。"无为"不是什么都不做——是"不需要额外的努力去保持不动"。

老子说"上善若水"。水之所以是水，不是因为它天天努力"不变"。它只是本来就是水。Intent 的 `let x = 10` 同理——`x` 就是 `10`，不需要努力、不需要 `const` 保护。

**哲学翻译**：

| 语言 | 变量默认状态 |
|------|------------|
| JavaScript/Python | 可变的（努力保持稳定） |
| Intent | 不可变的（本来就安定） |

---

## 1.4 `mut` 是一声宣言

```intent
let mut counter = 0;
counter = 1;  // "我承认，我在改变"
counter = 2;  // "我承认，我再次改变"
counter = 3;  // "我承认，我继续改变"
```

每一个 `mut` 都是一声宣言：**我承认我在改变世界。**

编程大部分时候不需要改变——数据流过管道，被转换、过滤、计算。在这些场景中，`let` 就够了。

但当你需要计数、需要累积、需要状态机——你写 `let mut`。你在说："OK，这里变了。"

这是一种**自觉的哲学**。你能区分"我在改造数据"和"我在改变状态"。

马克思说"哲学家们只是用不同的方式解释世界，而问题在于改变世界"——Intent 让"改变世界"变成一件需要声明的事。你不是不知不觉地在改，你写 `let mut`，你在做出承诺。

---

## 1.5 一切皆表达式

```intent
let result = 3 + 4 * 5;
print(result);  // 23
```

没有"语句"和"表达式"的二分。**你写的每一个东西都在生成一个值。**

很多语言中，`if` 是语句（不返回值），你得用三元运算符。`for` 是语句，你只能在里面操作副作用。

Intent 中，`if` 是表达式、`match` 是表达式、甚至 `try/catch` 也是表达式（生成 Result）。

这又是一个哲学选择：**你的每一个念头都在生成一个存在状态。** 不是在刻意"执行"什么，而是每一次思考本身就是产出。

## 1.6 练习：感觉差异

1. 把第1课代码中的所有 `let` 改成 `let mut`。重新跑。输出一样，但感觉不同——你感觉到不同了吗？
2. 试着写 `let x: Int = 10;`（显式标注类型）。对比 `let x = 10;`。你觉得哪个更"自然"？
3. 如果你入职第一天，有人告诉你"在这里，不写 `mut` 就不能改变量"，你的第一反应是什么？为什么？

---

## 1.7 小结

| 语法 | 哲学 |
|------|------|
| `let x = 10` | 声明即存在（心外无物） |
| 类型推断 | 心即理也（不需向外求证） |
| 默认不可变 | 无为（不需努力保持不动） |
| `let mut` | 自觉的改变（改变世界是宣言） |
| 一切皆表达式 | 每个念头都生成存在状态 |
