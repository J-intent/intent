## 7.1 你不孤独

```intent
import std.math;

let num = 3.0;
print(sqrt(num));   // 1.732...
print(abs(-5));     // 5
```

`import std.math` 不是技术操作——它是一句哲学声明。

**在我诞生之前，世界已经准备好了工具。** `sqrt` 不是你的发明，它是世界的赠予。

庄子说"天地与我并生"——天地既是父母，也先于你而存在。你在出生时就已拥有整个世界。`import` 就是这个"与世界连接"的仪式。

---

## 7.2 发明 vs 组合

```intent
let nums = [3, 1, 4, 1, 5, 9, 2, 6];
let s = sum(nums);
let c = len(nums);
```

你不写循环来求和。你不写遍历来数长度。

**你的工作不是发明，是组合。** 找到已有的模块，然后用管道和函数把它们串起来。

这是"万物一体之仁"的技术翻译：你不是独立的个体，你是生态中的一环。标准库就是你的"万物"。

---

## 7.3 推导式：组合的艺术

```intent
let evens = [x for x in nums if x % 2 == 0];
let doubled = [x * 2 for x in evens];
```

列表推导式 —— 一行代码完成筛选 + 变换。

这不是"更短的写法"，这是**一种不同的认知方式**。传统写法需要：
- 建立空列表
- for 循环遍历
- if 条件检查
- push 进列表

推导式一句话：**"从 nums 中取出 x，满足 x%2==0 的就放进来"。** 你的思维是"描述结果"，不是"描述过程"。

王阳明说"心即理也"——你的心直接把握了问题的本质，不需要逐步推导。

---

## 7.4 世界已经在那里

```intent
let d = {"name": "Intent", "version": "1.2", "status": "active"};
print(keys(d));  // ["name", "version", "status"]
```

`keys()`、`len()`、`str()`、`type_of()`... 70+ 内置函数。在你诞生前，世界的建构者们已经准备好了。

你用不了哪个？你可以自己实现。但你不必——**你的任务是借用，不是重造。**

---

## 7.5 Range：时间的礼物

```intent
let nums = range(5);
// [0, 1, 2, 3, 4]
```

`range(5)` 不是魔法——它是"时间的每一个瞬间"。0、1、2、3、4——就像你的每一天。

古人看天、观星、数日子。`range` 就是"数日子"的编程形式。你不需要自己数——世界给了你 `range`。
