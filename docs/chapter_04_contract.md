# 第4章：社会契约 — 代码不是孤立的存在

> **运行代码**：`python3 src/mini_intent.py examples/lesson_04_contract.intent`
> **哲学**：马克思"人是社会关系的总和"、卢梭"社会契约"
> **语法**：`requires`（前置条件）、`ensures`（后置条件）

---

## 4.1 没有函数是孤岛

```intent
def divide(a: Int, b: Int): Float requires b != 0 {
    return a / b;
};
```

这不是一个普通的函数定义。`requires b != 0` 是一个**社会契约**。

调用 `divide(10, 0)` 时，解释器会在执行函数体之前检查：`b != 0` 吗？

不，那就**拒之门外**。不是"等进去之后再崩溃"，而是根本不开门。

---

## 4.2 社会关系的总和

马克思说："人是社会关系的总和。" 你不仅是你的身体，你是你的家人、你的朋友、你的同事、你的社会角色。抽掉这些关系，"你"不再是你。

函数同理。`divide` 不是它自己——它是**和所有调用者的关系的总和**。

传统编程中，一个函数被调用时，你不知道它有什么隐含假设。你得看文档、看源码、在调用前加判断。这是"全靠自觉"的社会。

Intent 的契约系统把"自觉"变成了"契约"：

```
requires b != 0 ← 这是我的条件，不满足就别进来
ensures result * b == a ← 这是我的承诺，出去的东西一定满足这个
```

卢梭《社会契约论》的核心命题：**自由不是在规则外的无法无天，自由是在共同约定的规则下生活。** `requires` 和 `ensures` 就是这个"共同约定"。

---

## 4.3 进门前签合同

```intent
def transfer(from_balance, to_balance, amount: Int)
    requires from_balance >= amount
    requires amount > 0 {
    // ...
};
```

每一条 `requires` 是一条"进门条件"。

不是在函数内部 `if amount <= 0 { throw new Error(...) }`——那种写法的问题是，你已经在门内开始办事了才发现不对。你应该在门口就被拦下。

**契约 = 进门前签的合同。** 你不签，连门都进不去。

这种设计还有一个隐藏好处：**调用者自己就是有责任的。** 不是"这个函数报错了"，而是"我没有满足前置条件"。责任在谁？清楚明白。

---

## 4.4 出门前验货

```intent
def safe_divide(a: Int, b: Int): Float
    requires b != 0
    ensures result * b == a {
    return a / b;
};
```

`ensures result * b == a` 是一个**后置条件**。

"你进我的门，我带你去办事，然后出门之前——我们检查一下，结果是不是对的。"

`result` 是特殊的变量，代表函数的返回值。`result * b == a` 是数学上的恒等式：如果 `a / b = result`，那 `result * b` 一定 `== a`（不考虑精度）。

**有契约的函数，是一段可以被数学验证的代码。**

---

## 4.5 契约的哲学意义

1. **信任的重建**：在普遍不信任的世界中（null、undefined、类型错误...），契约是重建信任的唯一方式。你不信任函数？你签它的契约。

2. **责任的回归**：每个调用者知道它的责任（满足 requires），每个函数知道它的承诺（保障 ensures）。不是非对称的权力关系，是平等的相互约定。

3. **可验证的良知**：王阳明说"致良知"——良知不是玄妙的感觉，是可以检验的。"我有没有对调用者负责？" 你看 `ensures` 就知道。

---

## 4.6 练习：签合同

1. 写一个 `withdraw(balance: Int, amount: Int): Int` 函数。需要什么 `requires`？
2. 调用 `withdraw(100, 150)`，看契约怎么拒绝。
3. 加一个 `ensures result >= 0`。没有这个契约的取款函数会怎样？

---

## 4.7 小结

| 语法 | 哲学 |
|------|------|
| `requires` | 进门前签合同（社会契约） |
| `ensures` | 出门前验货（对结果负责） |
| `result` | 对产出负责的特殊变量 |
| 契约 = `requires + ensures` | 函数是它和所有调用者的关系总和 |
